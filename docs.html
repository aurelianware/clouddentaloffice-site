Quick start

Docker Compose

git clone https://github.com/aurelianware/clouddentaloffice.git
cd clouddentaloffice
docker-compose up -d

Portal on port 5000. API gateway on 5200. Per-service Swagger on 510x. Each service defaults to SQLite locally — no database setup required.

Build and test

dotnet restore CloudDentalOffice.sln
dotnet build CloudDentalOffice.sln --no-restore
dotnet test CloudDentalOffice.sln --no-restore --no-build

CI on main: Build and Tests. Portal, SchedulingService, and IntakeService test projects are in the solution. Zocdoc.IntegrationTests is not — it needs partner sandbox credentials and is dispatched separately.

Local Kubernetes

./scripts/deploy-local-k8s.sh
kubectl port-forward -n clouddental service/portal 5000:5000

Kind cluster named docker-desktop by default. Credentials are generated in-cluster, not stored in git.

Public APIs

docs/architecture/public-availability-api.md in the product repo. IntakeService source under src/Services/IntakeService. This marketing site does not duplicate the OpenAPI — it points at the source.
