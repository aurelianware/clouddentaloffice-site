Independent veteran-owned comprehensive practice. Cloud Dental Office is the system of record. The practice website is a channel, not the calendar.

What the pilot is

  • Zocdoc is a channel adapter over the public availability and booking-intake contract.
  • It reads free/bookable slots. It submits booking intent.
  • It does not become the calendar. It does not see PHI.
  • Staff still approve BookingRequest records in the portal.
What this site is not

Do not confuse the platform with the practice.

Not a patient site

Bookings, insurance questions, and clinical care live with the practice. This site is for operators evaluating the platform.

Not a certification

We do not claim a Zocdoc partnership, a marketplace badge, or a completed certification. The work is a pilot.

Not coupled in code

No practice name or internal patient, provider, or location identifier is hard-wired into IntakeService. Slugs, not database ids.

The public contract is documented on Scheduling APIs. Isolation and failure behavior are on Trust.

If you run a practice and want a channel on the same contract, talk to us.
