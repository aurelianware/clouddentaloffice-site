Current assurance status

What is public, what is configurable, what is not claimed.

Public & implemented

Intake isolation

API key compared in constant time. Rate limit 5/min per IP. Isolated inbox. BookingRequestedEvent over Service Bus. Token revalidation with 409 on stale slots.

Reference architecture

Private network for PHI

Portal, YARP, and every PHI-bearing service stay private. Only IntakeService is designed to face the internet.

Not currently claimed

Aurelianware certifications

This site does not claim that Aurelianware or Cloud Dental Office currently holds SOC 2 Type II or HITRUST certification.

Pilot, not certified

Zocdoc

Scheduling-API pilot only. Not presented as a partnership or marketplace certification.

Contractual

BAA, SLA, support

PHI processing, support coverage, and incident terms are defined per engagement. Visitor-submitted intake data must still be handled as sensitive healthcare information.

Customer-operated

Production effectiveness

Identity, networks, keys, logging, and recovery must be verified in the target environment. A repository is not a production control.

Vulnerability reporting

Report privately. Do not file PHI in public issues.

Do not disclose suspected vulnerabilities, PHI, credentials, or tenant data through public GitHub issues. Email sales@clouddentaloffice.com with the component, steps, and redacted evidence. The product SECURITY.md is in the repository.

Bring the architecture team. We will walk the isolation boundary in source.
